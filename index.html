Frequently Asked Questions

How do I transfer code from AI Chat to the Workspace?

When AI generates code in the chat, click the "Send to Workspace" button on the code block. It will automatically load directly into the Code Editor tab for instant editing and live preview.

Is ChatCode usable offline as a PWA?

Install availability depends on the deployed site having a valid web app manifest and service worker. The install button appears only when the browser supports installation.

How is my code executed safely?

All code previews are rendered inside a sandboxed HTML iframe right in your browser. No sensitive user data is sent to external execution servers.
